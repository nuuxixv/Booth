# 브랜딩 사양 시트 — Booth

> 이 시트는 서비스명 "Booth"의 표기·노출 규칙의 단일 진실 소스다.
> 화면 표기 변경 시 이 시트를 먼저 갱신한 다음 구현한다.
> **특히 §3 노출 범위(고객 접점 노출 금지)는 절대 규칙이다.** 임의 확대·축소는 건우님 명시 승인 후에만 허용된다.

## 참조 파일
- 로그인: `inpsyt-order-frontend/src/components/LoginPage.jsx` (로고/부제 영역 L336~347)
- 헤더: `inpsyt-order-frontend/src/components/AdminHeader.jsx` (좌상단 영역 L156~180)
- 탭 title: `inpsyt-order-frontend/index.html` (`<title>`) + 어드민 라우트 동적 제어 훅
- 관련 사양: `design-system/specs/A8_LoginPage.md`, `design-system/specs/S1_AdminShell.md`
- 디자인 원칙: `design-system/01_DESIGN_PRINCIPLES.md`, 토큰 `02_DESIGN_TOKENS.md`

## 1. 서비스명·표기 규칙
- **정식 표기: `Booth` 단독** (영문, 대문자 B).
- **inpsyt 접두어 미결합** — "inpsyt Booth"로 쓰지 않는다. 인싸이트는 로그인 화면의 로고로 소속을 표현하고, 서비스명은 Booth 단독으로 승격.
- **구두/사내 채팅**: "부스" (예: "부스에 올려놨어요").
- **워드마크는 텍스트 타이포로 구현** — 로고 이미지(SVG/PNG) 신규 제작하지 않는다. theme 토큰 기반 Typography.
- 워드마크 색: `text.primary` 또는 `palette.primary.main` (시안에서 확정). 볼드.

## 2. 태그라인
- **현재 미정 — 태그라인을 화면에 표시하지 않는다.** (2026-07-13 건우님: 후보 전부 부적절, 중요도 낮아 보류)
- 태그라인의 유일한 노출 예정 위치는 로그인 화면 워드마크 아래 한 줄이므로, 없어도 무방.
- 방향성(추후 재검토 시): "현장 마케팅 올인원" 계열. 확정 전까지 어떤 문구도 임의로 넣지 않는다.

## 3. 노출 범위 명세표 (절대 규칙)
Booth는 **어드민(내부 운영자 전용) 화면에만** 노출한다. 고객(의사·연구자)이 보는 접점에는 절대 노출하지 않는다.

| 화면/요소 | Booth 노출 | 근거 |
|---|:---:|---|
| 로그인 화면 (LoginPage) | **O** | 어드민 진입점 |
| 어드민 헤더 (AdminHeader) 좌상단 | **O** | 어드민 전 페이지 상시 앵커 — **서비스 표기의 유일한 상시 위치** |
| 어드민 사이드바 (AdminSidebar) 상단 로고·서비스명 | **X (제거)** | 2026-10-12 건우님. 헤더 "Booth"와 사이드바 "인싸이트 현장주문"이 겹쳐 보여 사이드바 쪽을 뺌. 인싸이트 소속은 로그인 화면 로고로 표현(§5) |
| 어드민 각 페이지 본문 | X | 헤더로 충분, 본문 중복 불필요 |
| 브라우저 탭 title — 어드민 라우트 | **O** | 동적 title로 어드민에서만 "Booth" |
| 브라우저 탭 title — 고객 라우트 | **X** | 고객 노출 → 중립 유지 |
| 파비콘 | **X** | 공용 자원, 고객도 봄 → 인싸이트 유지 |
| 고객 주문 화면 (OrderPage 등) | **X** | 고객 접점 |
| 고객 주문 완료·조회·영수증 | **X** | 고객 접점 |
| 알림톡 | **X** | 고객 접점 + 승인 템플릿 변경 금지 |

**구현 시 반드시**: `document.title`을 라우트별로 동적 제어해 어드민 경로에서만 "Booth"가 뜨게 한다. `index.html`의 정적 `<title>` 기본값은 고객 기준 중립(현행 "인싸이트 주문서" 유지)으로 둔다.

## 4. 화면별 적용 스펙 (현재 → 변경 후)

### 로그인 (`LoginPage.jsx`)
- **현재**: 인싸이트 `/LOGO.svg` (h40) + caption "인싸이트 현장주문 어드민"
- **변경 후 (세로 2단 스택)**:
  1. 인싸이트 `/LOGO.svg` — 소속 앵커. 유지(크기 축소 검토 가능, 예 h32)
  2. `Booth` 워드마크 — 텍스트 타이포(볼드), 서비스명 주역
  - 기존 caption "인싸이트 현장주문 어드민"은 **제거** (태그라인 미정이므로 3단째 비움)
- 위계 원칙: 소속 = 인싸이트(로고), 서비스 = Booth(워드마크).

### 헤더 (`AdminHeader.jsx`)
- **현재**: 좌측 = 모바일 햄버거만(md↑ 공백), 우측 = 피드백/알림/유저
- **변경 후**: 좌상단(md↑)에 `Booth` 워드마크 텍스트 추가 (약 20~22px 볼드, `text.primary`). 모바일은 햄버거 옆 배치.
  - 클릭 시 대시보드 이동은 선택(구현 편의에 따라).
  - 인싸이트 로고 병치 불필요 — 로그인에서 소속 각인 완료. 헤더는 Booth 워드마크만.
  - 라우트 라벨(PageHeader)은 기존 유지. 브랜드 앵커와 역할 분리.

### 브라우저 탭 title (`index.html` + 라우트 훅)
- **현재**: 정적 `"인싸이트 주문서"`
- **변경 후**: 정적 기본값은 중립 유지. 어드민 라우트에서만 `document.title`을 "Booth" 또는 "Booth — {페이지명}"으로 동적 설정.

### 파비콘
- **변경 없음** (공용·고객 노출 → 인싸이트 유지).

## 5. 톤·제약
- **theme 토큰만 사용** — `text.primary`/`text.secondary`, `radii`, MUI `Typography` variant. 임의 색·폰트 신설 금지.
- **AI 시그니처 금지** — 그라데이션 배경, 의미 없는 컬러 인디케이터, 데모 장식 금지. 담백한 타이포만.
- **인싸이트 소속감 유지** — 로그인의 인싸이트 로고 존치가 소속 근거.
- **만족 중인 현행 레이아웃·터치 영역 훼손 금지** — 브랜딩은 얹기만, 기존 UX 불변.

## 6. 비적용 항목 (오해 방지용 명시)
- **리네이밍 안 함**: 레포명(`inpsyt-order-frontend`), DB, URL, Vercel 링크(`inpsytorder.vercel.app`) 전부 현행 유지. 도메인 미구매 상태.
- 코드/폴더/슬러그 리네이밍은 향후 도메인 구매 시 별건(CTO 트랙)으로 분리.
- 파비콘·고객 경로 문구는 현행 유지.
